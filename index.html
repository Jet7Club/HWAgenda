3j / 7j / 10j — affiche les 3, 7 ou 10 prochains jours.
PDF PRO — ouvre l’impression/export PDF de l’agenda affiché.

↓ Charger GitHub — recharge les tâches de référence stockées sur GitHub.
Connecter Google Calendar — ouvre l’autorisation Google pour relier Agenda HW à Calendar.
Test → Google — après connexion, crée un seul événement test dans Google Calendar.
Modifier — charge une tâche dans le formulaire pour la modifier.
Exécuté — marque l’occurrence de la tâche comme terminée.
Supprimer — retire la tâche de l’agenda et la place dans la corbeille interne.
Case à cocher — marque/démarque une occurrence comme exécutée.
UI / UNI / INU / NUNI — catégorie de priorité. Importance 1–10 — niveau d’importance de la tâche.
PERSO / PRO — type de tâche. Les tâches PRO suivent les jours ouvrables.
Récurrence — ponctuelle, quotidienne, hebdomadaire, mensuelle, 3 mois, 6 mois ou annuelle. La date de fin est optionnelle.
